# dsh-warm-minimal

Optional minimal bootstrap and configurable coordinator/worker model visibility for DeepSeek Harness. Package identity: `dsh-warm-minimal@0.2.0`.

This directory is the installable Bundle and browser package. Runtime sources, presets, configuration and generated `lib/` are package-owned. Repository maintenance commands and the Host patch live at the workspace root; use the [workspace README](../../README.md) and [STATE maintenance map](../../.intent/state/STATE.md#installation-and-maintenance-map) before installing, rebuilding or removing it.

Setup/removal support only the Host revision declared by STATE and require explicit checkout, Home and profile selection. They default to inspection and never restart a service.
